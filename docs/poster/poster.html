Spellcast

ไม้กายสิทธิ์ที่รู้ว่าคุณวาดคาถาอะไร

A wand that reads the spell you draw, on the board itself.

กดปุ่มค้างแล้ววาดคาถาในอากาศ บอร์ด Arduino UNO R4 WiFi บนไม้จะจำแนกท่าเองด้วย Dynamic Time Warping (DTW) ไม่ต้องพึ่งคลาวด์ จากนั้นก็แสดงไอคอนบน LED matrix และส่งผลผ่าน WiFi ให้โน้ตบุ๊กทำงานตามคาถาทันที

เส้นเรืองแสงบนโปสเตอร์ทุกเส้นคือท่าร่ายจริงที่ไม้บันทึกไว้ตอนฝึก ส่วนไอคอนจุดสีแดงคือภาพเดียวกับที่ LED matrix บนบอร์ดแสดง

How a cast works

จากข้อมือถึงคาถา
Holdกดปุ่มค้างแล้ววาด

บอร์ดบันทึกเฉพาะตอนกดค้าง ปล่อยปุ่มเมื่อไหร่ก็อ่านคาถาทันที

Sampleเก็บค่า 100 ครั้งต่อวินาที

MPU6050 วัดการหมุนลงบัฟเฟอร์ FIFO ของตัวเอง WiFi ช้าแค่ไหนก็ไม่ทำให้ข้อมูลหาย

Traceแปลงเป็นเส้น 32 จุด

รวมการหมุนเป็นเส้นที่ปลายไม้วาด เลือกจุดห่างเท่ากัน ความเร็วกับมือสั่นจึงไม่มีผล

Matchเทียบด้วย DTW

เทียบกับตัวอย่างที่ฝึกไว้คาถาละ 3 ครั้ง ใกล้อันไหนสุดก็เป็นคาถานั้น ไกลเกินไปก็ fizzle

Castบอกโน้ตบุ๊กก่อน

ส่ง UDP ผ่าน WiFi ให้โน้ตบุ๊กเริ่มทำงานก่อน แล้ว LED matrix ค่อยแสดงไอคอน

Resultsผลการทดสอบ

100%ท่าร่ายจำลอง 1,000 ครั้ง จำแนกถูกทั้งหมด
87.8%เส้นที่วาดมั่ว ระบบปัดตกเป็น fizzle
100 Hzอัตราเก็บค่าไจโรระหว่างร่าย
15ตัวอย่างที่ฝึกไว้ เก็บใน EEPROM และสำรองบนโน้ตบุ๊ก

The systemไม้ โน้ตบุ๊ก และหน้าเว็บ
