บทคัดย่อ

Spellcast คือไม้กายสิทธิ์ที่รู้ว่าผู้ถือวาดคาถาอะไรในอากาศ แล้วสั่งงานคอมพิวเตอร์ตามคาถานั้น ตัวไม้ใช้บอร์ด Arduino UNO R4 WiFi เซนเซอร์ GY-521 (MPU6050) ที่ปลายไม้ และปุ่มกดหนึ่งปุ่ม

ระหว่างที่กดปุ่มค้าง เซนเซอร์จะวัดการหมุนของไม้ 100 ครั้งต่อวินาที บอร์ดรวมค่าที่ได้เป็นเส้นทางที่ปลายไม้ลากผ่าน เลือก 32 จุดที่ห่างเท่า ๆ กันตามเส้น แล้วปรับตำแหน่งกับขนาดให้เป็นมาตรฐาน จะร่ายเร็วหรือช้า มือสั่นหรือไม่ ก็ไม่มีผล ที่เหลือคือรูปร่างของเส้นอย่างเดียว จากนั้นบอร์ดเทียบรูปร่างนี้กับตัวอย่างที่ฝึกไว้คาถาละ 3 ครั้งด้วย Dynamic Time Warping (DTW) โดยคำนวณบนบอร์ดเองทั้งหมด ไม่ต้องส่งข้อมูลไปคลาวด์

พอปล่อยปุ่ม LED matrix ก็แสดงไอคอนของคาถา และบอร์ดส่งผลผ่าน WiFi ไปยังเซิร์ฟเวอร์ Python บนโน้ตบุ๊ก คาถาทั้ง 5 สั่งงานโน้ตบุ๊กได้ตั้งแต่เพิ่มหรือลดเสียง เปิดลิงก์ ไปจนถึงเล่นหรือหยุดวิดีโอ YouTube หน้าเว็บก็แสดงเส้นที่ไม้วาดแบบเรียลไทม์ด้วย และถ้าคลิกปุ่มสามครั้ง ไม้จะกลายเป็นเมาส์ไร้สาย

ผลทดสอบกับท่าร่ายจำลอง 1,000 ครั้ง ตัวจำแนกตอบถูกทุกครั้ง และปัดเส้นที่วาดมั่วตกเป็น fizzle ได้ 87.8% ส่วนไม้จริงร่ายได้ครบทั้ง 5 คาถาตามที่เห็นในวิดีโอ

Abstract (English)

Spellcast is a wand that knows which spell you drew in the air and makes the computer act on it. It is an Arduino UNO R4 WiFi, a GY-521 (MPU6050) gyro at the tip, and one button.

While the button is held, the gyro measures the wand's rotation 100 times a second. The board adds that up into the path the tip traced, takes 32 evenly spaced points along it, then centres and scales them, so speed and hand tremor stop mattering and only the shape is left. It compares that shape with three trained examples of each spell using Dynamic Time Warping (DTW), entirely on the board.

On release, the LED matrix shows the spell's icon and the result goes over WiFi to a Python server on the laptop, which turns the volume up or down, opens a link, or plays and pauses YouTube. A web page draws the wand's motion live, and a triple-click turns the wand into an air mouse.

On 1,000 simulated casts the classifier was right every time and rejected 87.8% of random scribbles. On the real wand, all five spells work as shown in the video.

จากการสะบัดข้อมือ สู่คาถา

  1. กดค้าง

    บอร์ดบันทึกเฉพาะตอนกดปุ่มค้างไว้ LED matrix จะขึ้นกรอบว่าง ๆ ให้รู้ว่ากำลังฟังอยู่ ปล่อยปุ่มเมื่อไหร่ บอร์ดก็อ่านคาถาทันที

  2. เก็บค่า

    MPU6050 เก็บค่าลงบัฟเฟอร์ FIFO ของตัวเองวินาทีละ 100 ครั้ง WiFi จะส่งช้าแค่ไหนข้อมูลก็ไม่หาย ส่วนฟิลเตอร์ 21 Hz ในตัวเซนเซอร์ก็ตัดอาการมือสั่นออกไปก่อนถึงบอร์ด

  3. ลากเส้น

    บอร์ดรวมการหมุนเป็นเส้นที่ปลายไม้วาด แปลงเป็นแกนของไม้ (ขึ้นลง ซ้ายขวา และการบิด) เลือก 32 จุดที่ห่างเท่ากัน แล้วปรับให้อยู่ตรงกลางและขนาดเท่ากัน การบิดข้อมือนับแค่ 30% เพราะแต่ละคนบิดข้อมือไม่เหมือนกัน

  4. เทียบ

    Dynamic Time Warping เทียบรูปร่างนี้กับตัวอย่างที่ฝึกไว้ 15 อัน คาถาละ 3 อัน และรับมือกับการวาดเร็วบ้างช้าบ้างได้ ใกล้อันไหนที่สุดก็เป็นคาถานั้น ถ้าไกลจากทุกอัน คาถาก็ fizzle

  5. ร่าย

    โน้ตบุ๊กรู้ก่อน บอร์ดส่ง UDP หนึ่งแพ็กเก็ต ส่งซ้ำสองรอบเผื่อ WiFi ทำหล่น ผลบนโน้ตบุ๊กจึงเริ่มในเสี้ยววินาที แล้ว LED matrix ค่อยเล่นไอคอนของคาถา

อุปกรณ์

  • Arduino UNO R4 WiFiทำงานทุกอย่าง ทั้งเก็บค่า จำแนกคาถา คุม LED matrix 12×8 และต่อ WiFi ผ่านชิป ESP32-S3 บนบอร์ด
  • GY-521 (MPU6050)ไจโรและตัววัดความเร่ง ติดเทปไว้ที่ปลายไม้ เก็บค่าลง FIFO ของตัวเอง
  • ปุ่มกดอยู่ใต้นิ้วโป้ง ทุกคำสั่งคือจังหวะการกดปุ่มนี้ปุ่มเดียว
  • Passive buzzerไม่บังคับ ใส่แล้วได้เสียงช็อตของ Expelliarmus กับเสียงเตือนตอนเซนเซอร์กลับมา
  • ไม้ สายจัมเปอร์ และเทปใช้ไฟจาก USB หรือพาวเวอร์แบงก์ก็ได้ เพราะทั้งการร่ายและโหมดเมาส์ส่งผ่าน WiFi
