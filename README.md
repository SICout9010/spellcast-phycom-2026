## บทคัดย่อ

ระหว่างที่กดปุ่มค้าง เซนเซอร์ GY-521 (MPU6050) ที่ปลายไม้จะวัดการหมุนของไม้ 100 ครั้งต่อวินาที บอร์ดรวมค่าที่ได้เป็นเส้นทางที่ปลายไม้ลากผ่าน เลือก 32 จุดที่ห่างเท่า ๆ กันตามเส้น แล้วปรับตำแหน่งกับขนาดให้เป็นมาตรฐาน จะร่ายเร็วหรือช้า มือสั่นหรือไม่ ก็ไม่มีผล จากนั้นบอร์ดเทียบรูปร่างนี้กับตัวอย่างที่ฝึกไว้คาถาละ 3 ครั้งด้วย Dynamic Time Warping (DTW) โดยคำนวณบนบอร์ดเองทั้งหมด

พอปล่อยปุ่ม LED matrix ก็แสดงไอคอนของคาถา และบอร์ดส่งผลไปยังเซิร์ฟเวอร์ Python บนโน้ตบุ๊ก หน้าเว็บก็แสดงเส้นที่ไม้วาดแบบเรียลไทม์ด้วย ถ้าคลิกปุ่มสามครั้ง ไม้จะกลายเป็นเมาส์ไร้สาย ผลทดสอบกับท่าร่ายจำลอง 1,000 ครั้ง ตัวจำแนกตอบถูกทุกครั้ง และปัดเส้นที่วาดมั่วตกเป็น fizzle ได้ 87.8%

## วิธีใช้งาน

1. **Arduino IDE:** ติดตั้งบอร์ด "Arduino UNO R4 Boards" และไลบรารี **ArduinoGraphics**
2. คัดลอก `firmware/spellcast/arduino_secrets.example.h` เป็น `arduino_secrets.h` แล้วใส่ชื่อและรหัส WiFi (ไฟล์นี้ไม่ขึ้น GitHub) ฮอตสปอตมือถือใช้ได้ดีที่สุด
3. เปิดเซิร์ฟเวอร์บนโน้ตบุ๊กที่ต่อ WiFi เดียวกัน
   ```bash
   python3 server/server.py 8050
   ```
   เซิร์ฟเวอร์จะพิมพ์ที่อยู่ เช่น `http://192.168.1.50:8050` ให้เอา IP ไปใส่ใน `SERVER_IP` และพอร์ตใน `SERVER_PORT` ด้านบนของ `spellcast.ino`
4. อัปโหลด `spellcast.ino` ครั้งแรกให้บูตไม้แบบตั้งปลายขึ้นนิ่ง ๆ บอร์ดจะรู้เองว่าเซนเซอร์ติดอยู่ในทิศไหน
5. กดปุ่มค้าง 2 วินาทีแบบนิ่ง ๆ แล้วฝึกแต่ละคาถา 3 ครั้ง
6. เปิดที่อยู่ของเซิร์ฟเวอร์บนมือถือหรือโน้ตบุ๊ก หน้าเว็บจะสลับเป็น Live wand เองเมื่อไม้ส่งข้อมูลมา

**ไม่มีฮาร์ดแวร์ก็ลองได้:** เปิด `sim/index.html` แล้ววาดด้วยเมาส์ หรือรัน `python3 server/fake_wand.py 127.0.0.1 8050` คู่กับเซิร์ฟเวอร์ ส่วนชุดทดสอบรันด้วยคำสั่งนี้

```bash
cd test && c++ -O2 -std=c++17 test_dtw.cpp -o test_dtw && ./test_dtw
```

**ถ้าร่ายแล้ว fizzle บ่อย:** ดูระยะห่างของแต่ละคาถาใน Serial Monitor (115200) หรือบนหน้าเว็บ แล้วฝึกคาถานั้นใหม่ หรือเพิ่มค่า `REJECT` (ค่าเริ่มต้น 0.5) ด้านบนของ `spellcast.ino`
